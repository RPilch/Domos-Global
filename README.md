# Domos Global — GitHub Pages

Sitio web estático de Domos Global, preparado para publicarse desde la raíz de un repositorio de GitHub.

## Publicación

1. Subir a la raíz del repositorio **el contenido de esta carpeta**, no la carpeta contenedora.
2. En GitHub, abrir `Settings` → `Pages`.
3. En `Build and deployment`, seleccionar `Deploy from a branch`.
4. Seleccionar la rama `main`, carpeta `/(root)` y guardar.
5. El archivo `CNAME` ya contiene `domosglobal.com`.

La configuración DNS del dominio se realiza después en Cloudflare.
